# Rivelero Synthetic Observability Reference World

Deterministic 1 km x 1 km test world. Grid: 100 x 100 cells, 10 m, EPSG:32633.

Scenarios: flat visibility, directional FOV, ridge occlusion, overlap/exposure, redundancy and marginal gain, nodata-state classification, temporal events, and metadata fallback.

Exact GDAL edge-cell counts are intentionally not hard-coded. Establish them as regression references after the first validated Rivelero run.
